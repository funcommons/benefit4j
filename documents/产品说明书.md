# benefit4j 产品说明书

> **版本** v1.2.6 · **更新** 2026-08-22 · **状态** 已发布 · **维护** benefit4j 团队
> 以代码现状为准。framework4j v1.2.6 · Spring Boot 3.2.7 · 前端 Vue 3.5。

## 1. 产品定位

**benefit4j**（User Benefit Middle-platform）是面向多业务系统接入的**用户权益中台**。各业务系统作为租户（App）接入，中台提供：

- 完备的**后台管理页面**（平台端 + 租户端，支持独立登录或免密嵌入）
- 高可用的**开放 API**（订阅发放、消费核销、退回、补偿）
- 统一的**计量型权益模型**（额度点数，非金额）

典型场景：每月赠送算力点 + 独立充值永不过期点、API 调用次数包、短信条数包、AI Token、转码时长、存储额度等——同一权益项下多种来源余额按优先级扣减。

## 3. 领域模型（三层架构）

代码实体与表分三层，与 PRD「定义层 / 产品层 / 订阅层」对齐：

### 3.1 模板层（定义层，平台共享，无租户隔离）

`ubmp_benefit_tmpl_item / _set / _ref` —— 平台级共享的权益模板，带 `ext JSONB` 动态属性。`ubmp_audit_log` 为审计表（framework4j-audit 写入，Hash Chain 防篡改）。

### 3.2 产品层（租户隔离，带 tenant_id）

| 实体/表 | 角色 |
|---|---|
| `UbmaTenant` / `ubma_tenant` | 接入租户，含 `tenant_secret`（AES-256-GCM 加密存储） |
| `UbmaBenefitItem` / `ubma_benefit_item` | 权益项原子类型（如"算力点"） |
| `UbmaBenefitSet` / `ubma_benefit_set` | 权益集（打包售卖单元，含周期/时长/优先级） |
| `UbmaBenefitRef` / `ubma_benefit_ref` | set↔item 多对多 + 单项配额 |

### 3.3 订阅层（用户资产 + 流水）

| 实体/表 | 角色 |
|---|---|
| `UbmaSubscribe` / `ubma_subscribe` | 用户订阅主单（quotaLimit / periodConsumed / frozenConsumed / version 乐观锁） |
| `UbmaSubscribeItem` / `ubma_subscribe_item` | **订阅明细 = 余额桶**（quotaLimit / periodConsumed / frozenConsumed / version + 桶字段，见 §5） |
| `UbmaConsume` / `ubma_consume` | 扣减流水（TCC 三阶段：reserve/commit/release，`expire_time` 为 TCC 冻结超时） |
| `UbmaCompensation` / `ubma_compensation` | 补偿流水（ADD/REDUCE） |
| `UbmaRefund` / `ubma_refund` | 退款流水 |
| `UbmaUnsubscribe` / `ubma_unsubscribe` | 退订审计 |
| `UbmaMigration` / `ubma_migration` | 跨 set 升降级迁移（greenfield，未实现） |

**命名约定**：DB `snake_case` ↔ Java `lowerCamelCase`（MyBatis Plus 自动转换）↔ API `snake_case`（Jackson 全局策略）。三层命名天然一致。

## 4. 双模式架构（starter 模式）

benefit4j 同一份代码/jar，通过 `application.yml` 开关适配三类部署：

| 场景 | `benefit4j.{domain}.mode` | `enable-api` | 行为 |
|---|---|---|---|
| 业务方同进程嵌入 | `local`（默认） | `false` | `@Autowired BenefitXxxClient` 走本地 Java 方法，零 HTTP |
| 业务方跨进程调用 | `remote` | — | 同 Client 接口，框架自动改 HttpTransport 远程调用 |
| 独立部署（自起 HTTP） | `local` | `true` | Controller 自动注册 `/benefit/api/v1/*` 路由，对外暴露 OpenAPI |

**4 个 Client 接口**（业务方唯一注入点，不感知 local/remote）：
`BenefitRuntimeClient` / `BenefitTenantClient` / `BenefitPlatformClient` / `BenefitOpsClient`。

测试环境（`benefit4j-it/src/test/resources/application.yml`）当前配置：
```yaml
benefit4j:
  tenant.mode: local
  ops.enable-api: true
  runtime.enable-api: true
  platform.enable-api: true
```

## 5. 多源额度桶（V1.2.0 核心特性）

同一权益项下可存在多种来源/过期策略/优先级的余额批次。`ubma_subscribe_item` 即"桶"，新增 3 字段：

| 字段 | 语义 | 取值 |
|---|---|---|
| `source_type` | 来源标签 | `SUBSCRIPTION` / `TOPUP` / `COMPENSATION` / `GRANT` / `PROMOTION` |
| `expires_at` | 单桶过期 | NULL = 永不过期 |
| `bucket_priority` | 单桶优先级 | 数字越大越优先扣减（继承自 set.priority 或补偿指定） |

### 扣减流程
`findDeductionCandidates` 一次性拉所有候选桶（`EXISTS` 关联 ACTIVE 订阅 + 未过期过滤），按 `bucket_priority DESC → expires_at ASC NULLS LAST → created_at ASC` 排序，`postConsumesDirect` 跨桶排空（单请求多行 `ubma_consume`，`external_order_id` 用 `--<seq>` 区分）。主循环含乐观锁。

### 补偿流程
`postCompensations` 的 `ADD` 分支 **INSERT 新桶**（而非改 quotaLimit），支持"加 5000 永不过期"——新桶带 `source_type=COMPENSATION/TOPUP`、独立 `expires_at`、`bucket_priority`。

### 索引
`idx_user_item_active_priority ON ubma_subscribe_item (tenant_id, item_id, bucket_priority DESC, expires_at ASC NULLS LAST) WHERE is_deleted=0`（V1.2.1 迁移）。

### 部分唯一约束
`uk_subscribe_item_source ON ubma_subscribe_item (subscribe_id, item_id, source_type) WHERE is_deleted=0`——同一订阅同一项同来源唯一，防重复补偿。

## 6. API 总览

所有路由统一前缀 `/benefit/api/v1`，按角色分域。完整路径见 `benefit4j-starter/.../controller/`。

| 域 | 前缀 | 鉴权 | 职责 |
|---|---|---|---|
| **auth** | `/auth/token` | 无 | OAuth2 client_credentials 换 AccessToken（JWT） |
| **platform** | `/platform/*` | `@RequiresToken(APP)` | 平台管理：租户接入、全局/项模板、跨租户查询、统计 |
| **tenant** | `/tenant/*` | `@RequiresToken(APP)` | 租户运营：权益项/集 CRUD、订阅发放、补偿、退款 |
| **runtime** | `/runtime/*` | `@RequiresToken(APP)` + `@RequiresSignature` | 对外开放：订阅/消费(TCC)/退款/资产查询 |
| **ops** | `/ops/*` | `@RequiresToken(OPS)` | 运维：健康探针、指标、缓存淘汰、周期结转、一次性迁移 |

### 关键端点
- **订阅发放**：`POST /runtime/subscriptions`、`POST /tenant/subscriptions`
- **直接消费**：`POST /runtime/consumes/direct`（跨桶排空）
- **TCC 三阶段**：`/consumes/reserve` → `/commit` → `/release`（`expire_time` 为冻结超时）
- **退款**：`POST /runtime/refunds`、`POST /tenant/consumes/{consume_id}/refund`
- **补偿**：`POST /tenant/compensations`（ADD 创建新桶）
- **资产查询**：`GET /runtime/users/{userid}/assets`

## 7. 安全能力（framework4j v1.2.6 接入）

framework4j 16 模块中 benefit4j **落地 13 个**（datetime/api 不适用，cache 暂未接）：

| 能力 | 注解/配置 | benefit4j 接入点 | 验证状态 |
|---|---|---|---|
| **AccessToken** | `@RequiresToken` | 全 Controller，APP/OPS 策略 + Redis nonce 单会话 | ✅ |
| **OpenID** | `@OpenId` | 15 处路径参数（12 字符混淆 + 校验位） | ✅ |
| **接口签名** | `@RequiresSignature` | runtime 域类级（X-Access-Key/Timestamp/Nonce/Signature HMAC-SHA256） | ✅ 正确签名 200 / 无签名 401 |
| **限流** | `@RateLimit` | runtime 10 端点（消费类 50/分、查询类 300/分，scope=APP） | ✅ 51 次 429 |
| **幂等** | `Idempotency-Key` | 资金写操作 path-patterns（订阅/消费/补偿/退款/reset-secret） | ✅ SETNX+回放 |
| **审计** | `@Auditable` | 补偿/消费/退款/订阅/应用 7 方法 → `ubmp_audit_log` Hash Chain | ✅ |
| **字段加密** | `@TableField(typeHandler=EncryptedFieldTypeHandler)` | `tenant_secret` AES-256-GCM 自动加解密 | ✅ DB 密文/读回明文 |
| **字段脱敏** | `@Sensitive` | `tenant_secret` 响应脱敏（保留前 2 后 4） | ✅ |
| **SQL 追踪** | `framework4j.datasource.sql-tracing` | Druid Filter 注入 `/*traceid=xxx,topic=*/` 到 SQL | ✅ filter 注入 default 数据源 |
| **多数据源** | `MultiDataSourceManager` | `framework4j.datasource` 配置 | ✅ |
| **多 Redis** | `MultiRedisManager` | `framework4j.redis` 配置 | ✅ |
| **统一响应** | `ApiResponse`/`ApiError` | 全局信封 + GlobalExceptionHandler | ✅ |
| **分布式 ID** | `IdObfuscator` | 雪花 ID ↔ 12 字符 OpenID | ✅ |

### 安全链路（runtime 域请求）
`IdempotencyBodyCacheFilter`(缓存body) → `AccessToken` 鉴权 → `@RequiresSignature` 签名验证(防重放) → `@RateLimit` 限流 → `Idempotency` 幂等检查 → Controller → `@Auditable` 审计。

### tenant_secret 加密迁移
历史明文 `tenant_secret` 通过 `POST /ops/migrate/encrypt-app-secret`（`@ConditionalOnProperty benefit4j.migration.app-secret-encrypt`）一次性全量加密。开关默认关，运维开一次跑完即关。

## 8. 前端（双端管理后台）

前端 `frontend/`，基于自研 Fc* SDK 组件库，分平台端 + 租户端两套独立登录。

### 平台端（`/benefit/app/platform` + `/benefit/platform/app`）
| 页面 | 职责 |
|---|---|
| `PlatformLogin.vue` | 平台登录 |
| `PlatformDashboard.vue` | 平台首页 |
| `Tenants.vue` | 租户接入管理 |
| `PlatformItems.vue` / `Items.vue` | 权益项 |
| `Sets.vue` | 权益集 |
| `SetTemplates.vue` / `ItemTemplates.vue` / `PlatformLogin...Templates` | 模板管理 |

| `ConsumeDirect.vue` | 直接消费 |
| `EmbedDocs.vue` / `EmbedTest` | 嵌入接入文档 |

### 租户端（`/benefit/app/tenant` + `/benefit/tenant/app`）
`TenantLogin` / `TenantDashboard` / `Items` / `Sets` / `Subscriptions` / `Consumptions` / `Compensations` / `TenantTemplates`。

### 跨标签页登录态
`authBus`（BroadcastChannel `benefit4j-auth`）+ storage 事件降级：A 页被踢/过期 → B/C 页同步跳登录页。

### 401 拦截器精细化
`benefitClient.ts` 区分业务码 10201(过期)/10205(踢人)/10208(吊销)，不同处理。

## 9. 配置（application.yml 要点）

```yaml
framework4j:
  redis:
    enabled: true
    datasources:
      default: { host: localhost, port: 6379 }
  datasource:
    enabled: true
    datasources:
      default:
        url: jdbc:postgresql://localhost:5432/benefit4j?stringtype=unspecified  # JSONB update cast 治本
        # stringtype=unspecified: 让 PG 自动 cast string→jsonb, 修复 JacksonTypeHandler update 时 cast 失败
    sql-tracing:
      enabled: true
      mode: ALL                       # Druid Filter 注入 traceid
  access-token:
    enabled: true
    redis-name: default
    policies:
      APP: { key: [tenant_id], expire-time: 7200, auto-renew: true }
      OPS: { key: [tenant_id], expire-time: 7200 }
  signature:
    enabled: true
    path-patterns: ["/benefit/api/v1/runtime/**"]   # 对外 runtime 强制签名
  sensitive:
    enabled: true
    encryption-key: ${AES_KEY:...}    # 生产从 KMS 取, ≥32 字符
  idempotency:
    enabled: true
    header-name: Idempotency-Key
    body-hash-required: true
    path-patterns: [资金写操作路径]
  audit:
    enabled: true
    table-name: ubmp_audit_log
  rate-limit:
    enabled: true
    default-scope: APP
    path-patterns: ["/benefit/api/v1/runtime/**"]
benefit4j:
  security:
    platform:
      client-id: ${PLATFORM_CLIENT_ID:PLATFORM}
      client-secret: ${PLATFORM_CLIENT_SECRET:fvUQ54yPgrMg2v2X}
  migration:
    app-secret-encrypt: false         # 迁移时临时开 true, 跑完关
```
